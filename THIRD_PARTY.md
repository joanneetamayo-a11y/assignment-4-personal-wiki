# Third-party components and sources

The CLI/harness is original project code. Ollama and its bundled inference libraries are third-party runtimes; their licenses are included in the official runtime archive in `.local/runtime/`. Model weights are not submission files. Gemma 4's license and attribution travel with the official model package; see https://ai.google.dev/gemma/docs/core and https://ollama.com/library/gemma4:e2b.

The unchanged Ollama documentation snapshots in `vault/raw/` come from the publishers and URLs recorded in `sources.json`. They are documentation, not code to execute or assistant instructions. Follow the upstream Ollama repository license when redistributing them: https://github.com/ollama/ollama/blob/main/LICENSE.
